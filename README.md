# Qualcomm-firehoses
Qualcomm firehoses from many popular brands


This github repository is specifically for qualcomm firehoses.
I will also include some Sigs, a guide on how to use them, drivers and the EDL tools

All xiaomi firehoses have been checked by the Xiaomi firehose checker bot on TG



!!! WARNINGS !!!!

The /Xiaomi/No Auth/SNAPDRAGON 8 GEN 2.melf and /Xiaomi/No Auth/SNAPDRAGON 8 GEN ELITE.melf firehoses will PERMANENTLY brick your device if used on Toshiba / Kioxia UFS's, i do not know if the same applies to the /Xiaomi/No Auth/SNAPDRAGON 8 GEN 1.melf firehose
